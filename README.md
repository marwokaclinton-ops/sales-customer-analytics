# Sales Performance and Customer Analytics

## Project Overview
This project analyzes online retail transaction data to understand sales performance, product demand, and customer purchasing behaviour. It uses Python for data cleaning and exploratory data analysis, RFM analysis for customer segmentation, and Power BI for interactive dashboard reporting.

## Project Objectives
- Analyze monthly sales revenue trends.
- Identify top-performing products and countries.
- Calculate total revenue, orders, customers, and average order value.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Develop a Power BI dashboard to support business decision-making.

## Dataset
The project uses the Online Retail dataset from the UCI Machine Learning Repository. It contains retail transactions from December 2010 to December 2011.

Source: https://archive.ics.uci.edu/dataset/352/online+retail

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Power BI
- Git and GitHub

## Methodology
1. Inspect the raw transaction data.
2. Clean missing, duplicate, cancelled, and invalid sales records.
3. Calculate sales revenue using quantity multiplied by unit price.
4. Conduct exploratory data analysis.
5. Calculate RFM customer metrics and assign customer segments.
6. Develop an interactive Power BI dashboard.
7. Summarize findings and propose business recommendations.

## Project Structure
- `data/` — raw and processed datasets
- `src/` — Python scripts
- `notebooks/` — analysis notebooks
- `visuals/` — generated charts
- `dashboard/` — Power BI dashboard files

- `sql/` — SQL analysis files

## Key Outputs
- Cleaned retail transaction data
- Customer RFM segmentation
- Monthly sales trend chart
- Top products chart
- Interactive Power BI dashboard

## Limitations
Sales revenue is not profit because the dataset does not provide product costs or operating expenses. Some transactions also lack customer identifiers, limiting customer-level analysis.
